核心算法
机器人仿真用了哪些 AI/算法 知识
Dijkstra 最短路径
路径网络图 → 自动找最短路线。带缓存，切地图时清除，防跨地图污染。
有限状态机 FSM
机器人三态：轮巡 ↔ 服务 ↔ 返回。呼叫点四态：idle → pending → assigned → idle。
线性插值定位
getPositionOnPath() 基于 progress 0~1 实时计算机器人坐标，实现平滑移动。
粘性任务分配
同一呼叫点优先分配已绑定机器人，距离兜底。防止机器人反复切换目标。

Prompt工程
Caveman Mode — 对话Token压缩
什么是 Caveman Mode
通过 Claude Code 的 hooks 系统，每次对话自动注入指令：去掉冠词、废话、客套语，用简洁语言回复。

每条回复节省30-50% token
# 传统输出 (多余) "Sure! I'd be happy to help you with that. The issue you're experiencing is likely caused by..." # Caveman输出 (精准) "Bug in auth middleware. Token expiry check use < not <=. Fix:"
Hooks 系统
settings.json 配置自动化行为。每次 Claude 回复前/后自动执行脚本，无需手动提示。
三种强度
/caveman lite — 轻度压缩
/caveman full — 标准模式
/caveman ultra — 极简输出
自动豁免
安全警告、不可逆操作确认时自动切回正常语言，保证关键信息完整。
