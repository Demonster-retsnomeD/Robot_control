核心算法Core Algorithms
机器人仿真用了哪些 AI/算法 知识 What AI/Algorithm Knowledge Powers the Sim
🗺️ Dijkstra 最短路径Shortest Path
路径网络图 → 自动找最短路线。带缓存，切地图时清除，防跨地图污染。 Path network graph → auto-finds shortest route. Cached; cache cleared on map switch to prevent cross-map pollution.
⚙️ 有限状态机 FSMFinite State Machine
机器人三态：轮巡 ↔ 服务 ↔ 返回。呼叫点四态：idle → pending → assigned → idle。 Robot 3 states: patrol ↔ service ↔ return. Call point 4 states: idle → pending → assigned → idle.
📍 线性插值定位Linear Interpolation
getPositionOnPath() 基于 progress 0~1 实时计算机器人坐标，实现平滑移动。 computes real-time robot coordinates from progress 0~1, enabling smooth movement.
🎯 粘性任务分配Sticky Task Assignment
同一呼叫点优先分配已绑定机器人，距离兜底。防止机器人反复切换目标。 Same call point prefers its previously assigned robot; distance as fallback. Prevents robots from constantly switching targets.

Caveman Mode — 对话Token压缩 Caveman Mode — Compress Response Tokens
什么是 Caveman ModeWhat is Caveman Mode
通过 Claude Code 的 hooks 系统，每次对话自动注入指令：去掉冠词、废话、客套语，用简洁语言回复。每条回复节省 30–50% token。 Via Claude Code hooks, every conversation auto-injects instructions: drop articles, filler, pleasantries — reply in terse fragments. Saves 30–50% tokens per response.
# ❌ 传统输出Verbose output "Sure! I'd be happy to help. The issue is likely caused by..." # ✅ Caveman "Bug in auth. Token check use < not <=. Fix:"
⚡ Hooks 系统System
settings.json 配置自动化行为。每次 Claude 回复前/后自动执行脚本，无需手动提示。 settings.json configures automated behaviors. Scripts run before/after every Claude response automatically.
🔄 三种强度Three Levels
/caveman lite — 轻度压缩light compression
/caveman full — 标准模式standard mode
/caveman ultra — 极简输出ultra terse
🛡️ 自动豁免Auto-Exempt
安全警告、不可逆操作确认时自动切回正常语言，保证关键信息完整。 Security warnings and irreversible action confirmations auto-revert to full language to ensure nothing critical is lost.
