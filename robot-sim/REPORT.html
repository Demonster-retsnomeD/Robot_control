自动布局

实时反馈

拖动点位时显示坐标、高亮圆圈、十字光标。支持保存/撤销编辑。

支持点位类型：机器人(1-N)、轮巡点(A-Z)、呼叫点(I-IV)

点击两个关键点，系统自动追踪鼠标光标绘制光滑曲线。支持编辑、删除、保存单条路径。

交互式绘图，鼠标自动光滑曲线
实时预览所有路径

3️⃣ 轮巡路由系统 (12个函数)

从已有路径中选择路径段，组成轮巡序列。支持自动检查连接性和清理孤立路由段。

路由配置：patrolRoute = ["A-B", "B-C", "C-A"]
自动检查路径段连接性（前一条终点 = 后一条起点）
自动清理指向已删除点的路由段
诊断日志显示当前可用的路径段
4️⃣ 机器人调度系统 (22个函数)

两层状态机：Robot(轮巡 ↔ 服务) 和 CallPoint(空闲 → 待分配 → 已分配 → 完成)

粘性分配 — 同一呼叫点连续请求，继续用同一机器人
距离优化 — 从当前位置找最近路径节点，计算到目标距离
单独调速 — 每个机器人独立速度(1-20 m/s)，实时更新
服务周期 — 到达呼叫点 → 停留5秒 → 返回轮巡
5️⃣ 寻路系统 (9个函数 + 缓存)

Dijkstra最短路径算法，支持关键点和伪标签(x,y)节点。首次构建图后缓存，切换地图时自动清缓存。

图构建 — 从pathNetwork提取关键点+伪标签节点
节点映射 — 路径坐标自动识别为关键点或生成伪标签
缓存管理 — loadPreset/savePointConfigUI/savePaths时自动清缓存
时间复杂度 — O(n²)，缓存命中<5ms，首次构建~20ms
6️⃣ 任务分配算法 (8个函数)
检测呼叫请求 → 状态机转为pending
找最近的路径节点(距离<3px)
Dijkstra寻找最短节点路由
getFullPath()展开为完整坐标数组
分配给该机器人，状态转为assigned

🎯 8 Feature Modules
1️⃣ Point Management System (18 functions)

Two-Layer Editing

First layer: configure quantity; second layer: drag positions. Supports robots, patrol points, and call points.

Auto Layout

New maps auto-generate grid layout: robots left, patrol points center, call points right.

Real-time Feedback

Drag shows coordinates, highlighted circles, crosshair cursor. Save/undo support.

2️⃣ Path Editing System (16 functions)

Click two keypoints, system auto-traces mouse for smooth curve. Edit, delete, and save individual paths.

Interactive drawing with smooth mouse tracing
Real-time path preview
Prevents duplicate path creation
Paths stored as coordinate arrays
3️⃣ Patrol Route System (12 functions)

Select path segments to form patrol sequence. Auto-checks connectivity and cleans up orphaned route segments.

Route config: patrolRoute = ["A-B", "B-C", "C-A"]
Auto-validates path segment connectivity
Auto-removes routes referencing deleted points
Diagnostic logging shows available segments
4️⃣ Robot Dispatch System (22 functions)

Dual state machines: Robot(patrol ↔ service) and CallPoint(idle → pending → assigned → complete)

Sticky Assignment — Repeated calls on same point use same robot
Distance Optimization — Find nearest path node, compute distance to target
Independent Speed — Each robot has own speed (1-20 m/s), real-time control
Service Cycle — Arrive → stay 5s → return to patrol
5️⃣ Pathfinding System (9 functions + caching)

Dijkstra's shortest path, supports keypoints and pseudo-labels (x,y). Caches graph, auto-clears on map switch.

Graph Building — Extract keypoints + pseudo-label nodes from pathNetwork
Node Mapping — Path coordinates auto-identify as keypoints or pseudo-labels
Cache Management — Auto-clear on loadPreset/savePointConfigUI/savePaths
Time Complexity — O(n²), cache hit <5ms, first build ~20ms
6️⃣ Task Assignment Algorithm (8 functions)
Detect call request → state transitions to pending
Find nearest path node (distance <3px)
Dijkstra finds shortest node route
getFullPath() expands to full coordinate array
Assign to robot, state transitions to assigned
7️⃣ Preset System (10 functions)
Save preset — JSON serialize complete config (points+paths+patrol+robots)
Load preset — One-click switch entire map config
Delete preset — Confirmed permanent deletion
localStorage persistence — Data survives browser close
